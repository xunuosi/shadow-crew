## 一、本周结论

本周项目主线聚焦 **多 Agent 普通模式的高可靠编排、长上下文治理和会话隔离**，完成了三项关键工程闭环：

1. 普通协作模式由“重复携带全量上下文”升级为“会话水位线 + `<delta-events>` 增量上下文”，并落地首轮并发 Fan-out、Turn Barrier 和跨回复 `@mention` 聚合。
2. 大模型调用链路补齐安全上下文预算、结构化压缩和模式化 Session Key，兼顾 1M～2M 超长上下文模型与极小预算边界。
3. Agent 运行时的会话、MCP、工作区和缓存隔离完成加固，降低跨会话污染、路径越界、陈旧句柄与静默替换风险。

当前自动化质量基线全绿，未发现阻断性问题。项目已从核心能力开发阶段进入 **真实桌面端长链路验收、性能观测和发布收口阶段**。

## 二、关键进展

### 2.1 普通模式多 Agent 协同编排

- 新增基于会话水位线的增量上下文协议：冷启动注入议题背景，热会话仅投递未读 `<delta-events>`，单次最多 50 条增量事件。
- 完成并发执行下的水位线不变量，保证多个 Agent 在同一轮并发回复时不会漏读队友消息，也不会重复消费自身发言、系统消息或 Pending 占位。
- 首轮未 `@` 成员时向频道全部 Agent 并发派发；使用 `Promise.allSettled` Turn Barrier 汇总本轮结果，并对跨回复的 `@mention` 去重。
- 增加频道外成员拦截和“无新增提及即收敛”机制，减少无效唤醒与级联震荡。
- 修复多级接力漏帧问题，确保第 N 跳始终携带触发它的上一跳正文；5-Hop 级联回归通过。
- 新增普通模式协议规范及 TC-2.2 八轮定向接力测试设计，后续可在桌面端直接执行验收。

**验收证据**：普通模式与 Turn Barrier 专项测试 `20 passed / 0 failed`；热会话 Prompt 相比旧版全量级联 Prompt 实测缩减 `47.8%`。

### 2.2 上下文预算、压缩与模型配置

- 增加 Token 预算和模型安全上下文计算，支持 1M～2M 原生上下文模型，并将桌面端稳态预算控制为 512K，避免直接耗尽模型窗口。
- 新增模型配置面板，支持 `384k`、`1m` 等带单位输入、自动换算、图片能力开关和推理强度配置。
- 实现结构化 Memory 压缩，保证压缩后继续满足 user / assistant 角色交替约束，并保留架构决策、关键参数、未决争议和执行结果。
- 落地双模摘要器：优先使用微型 Agent 生成高密度摘要，异常或关闭时自动降级为规则压缩。
- 强化 33～200 Token 极小预算硬约束，覆盖超长单消息、连续压缩、标签逃逸、摘要拒答和网络失败等边界。
- 缓存增加内容指纹、Agent 作用域隔离和 LRU 淘汰，修复相近历史前缀碰撞及跨会话复用风险。
- 私聊、频道、标准议题和博弈议题使用独立 Session Key，并支持显式清理会话，避免模式切换继承污染。

**验收证据**：上下文压缩与治理专项测试 `136 passed / 0 failed`；10,020 Token 超长消息在 100 Token 预算下压缩至 94 Token，角色交替与硬预算断言均通过。

### 2.3 Agent 运行时与安全隔离

- MCP 客户端改为会话级绑定，不再跨会话或跨工作区复用；当前会话挂载失败时仅降级为纯文本推演，不使用其他工作区工具。
- `session/prompt` 严格校验活跃 Session，拒绝缺失或过期的 Session ID；会话清理时同步关闭对应生命周期资源。
- 工作区路径增加规范化与 `~/.shadow-crew` 边界校验，拦截绝对路径越界和 `..` 路径穿越。
- 修复陈旧重命名句柄的误匹配，确保例如 `@glmclaude` 只能规范化到有效成员，不误唤醒其他 Agent。
- MCP `str_replace` 增加目标字符串唯一性校验，防止多处匹配时静默修改错误位置。
- 收紧 `memoryBundle` 白名单，并加固摘要标签转义与接地真值率解析。

**验收证据**：提及与边界解析 `13/13` 通过；Rust MCP 工具测试 `9/9` 通过。

### 2.4 协同体验与可视化

- 在线协同状态统一为进度条式协作徽标，可展示当前接力轮次并点击跳转到原始提示词。
- 修复消息流横向滚动问题，输入框支持自动增高和方向键历史导航。
- Agent 中断后保持在线状态，减少因单轮异常导致的成员状态漂移。

### 2.5 博弈引擎质量回归

- 加固 CognoNexus 和 G-Frame 边界探针，覆盖按行、按字符上下文切片的脆弱场景。
- G-Frame 贝叶斯路由、模块白名单、爆炸半径冻结、依赖成环、增量反馈和局部有界重修等回归全部通过。
- 博弈模式关键机制与论文黄金算例保持稳定，未发现新增阻断缺陷。
