> **证据命名**：`用例ID_序号_截图或日志.png`

## 1. 测试准备

### 1.1 启动应用

```bash
cd /Users/xunuosi/Code/Lx/AI/shadow-crew
npm run dev:desktop
```

### 1.2 Agent 准备

至少准备以下角色并全部点击 Start：

1. 提案官：支持宿主 MCP 工具 `submit_module_decomposition`。
2. 红队挑战官：支持结构化红队质询。
3. 接地验证官：优先使用独立 Agent，不要与提案官共用。
4. 仲裁官：可以由人类首席仲裁官承担，也可以配置独立 Agent。

建议使用不同模型家族，避免同质化告警干扰判断。

### 1.3 测试工作区

执行用例会生成代码 Diff，禁止直接绑定当前主仓库。准备一个一次性工作区：

```bash
mkdir -p /private/tmp/shadow-crew-manual/demo
printf '<!doctype html><html><body><h1>Manual Test</h1></body></html>\n' \
  > /private/tmp/shadow-crew-manual/demo/index.html
cd /private/tmp/shadow-crew-manual
git init
git add .
git commit -m "manual test baseline"
```

在 Shadow Crew 中将专用测试频道或议题绑定到 `/private/tmp/shadow-crew-manual`。没有需要时不要点击“一键合入”，避免修改真实工作区。

### 1.4 测试数据

#### DATA-01：单模块、快速通道

```text
任务：创建一个单文件静态产品介绍页，仅修改 demo/index.html。

请优先调用 submit_module_decomposition，并严格满足：
1. 只提交 1 个模块，不要为了凑数生成第二个模块或 guard 模块；
2. complexity_level 使用 low_deterministic；
3. requires_red_team 使用 false；
4. routing_rationale 写明“单文件、无持久化、无并发、无不可逆副作用”。
```

#### DATA-02：单模块、LLM 强制红队

```text
任务：只修改 demo/index.html，增加一个静态产品介绍区块。

即使这是单文件任务，也请将 requires_red_team 设置为 true，并在 routing_rationale
中说明“需要红队检查文案、可访问性和边界条件”。只提交 1 个模块。
```

#### DATA-03：关键词解耦测试

```text
任务：仅修改 demo/index.html 中的静态文案。说明文字中可以包含“并发、锁、事务、鉴权、迁移”
这些词，但本任务没有任何运行时逻辑、数据库、权限或持久化。

请设置 complexity_level=low_deterministic、requires_red_team=false，并提交 1 个模块。
```

#### DATA-04：3 模块复杂任务

```text
请实现三个正交模块并调用 submit_module_decomposition：
1. 类型契约模块：只修改 demo/types.ts；
2. 业务引擎模块：只修改 demo/engine.ts，依赖类型模块；
3. 页面交互模块：只修改 demo/index.html，依赖业务引擎模块。

三个模块的 allowed_files 不得重叠，并为每个模块给出 requires_red_team 和 routing_rationale。
```

#### DATA-05：干净答辩直接收敛

```text
为手动验收页实现一个带 localStorage 草稿保存的表单。

初始提案请故意保留一个可被红队证伪的缺陷：读取草稿时没有处理 JSON.parse 异常。
红队必须给出具体反例；验证官必须记录至少 1 项证伪；答辩阶段提案官必须修复该缺陷，
并给出可复现的修复证据和防御补丁。答辩后不得再保留未解决证伪项或契约越界。
```

#### DATA-06：答辩仍被证伪

```text
为手动验收页实现 localStorage 草稿保存。

初始方案故意包含未捕获 JSON.parse 异常；红队提出反例，验证官记录证伪。
答辩阶段继续保留该缺陷，只解释而不修改代码；请验证官在答辩复核中继续记录新的证伪项。
```

#### DATA-07：不支持 MCP 的保守兜底

使用一个不支持宿主 MCP 工具、但能正常参与博弈讨论的 Agent 发起 DATA-01。
